Write a variance-stabilized count matrix

Usage: rsdeseq2 vst [OPTIONS] --counts <COUNTS> --output <OUTPUT>

Options:
      --counts <COUNTS>
          Tab-delimited count matrix with gene IDs in the first column
      --design <DESIGN>
          Numeric design matrix TSV. Required with --blind false
      --blind <BLIND>
          Ignore the design and use an intercept-only trend fit [default: true] [possible values: true, false]
      --normalization-factors <NORMALIZATION_FACTORS>
          Optional gene x sample normalization-factor TSV
      --size-factors <SIZE_FACTORS>
          Optional sample-level size-factor TSV
      --observation-weights <OBSERVATION_WEIGHTS>
          Optional gene x sample observation-weight TSV
      --method <METHOD>
          Size-factor method [default: ratio] [possible values: ratio, poscounts]
      --geometric-means <GEOMETRIC_MEANS>
          Optional gene x geometric-mean TSV used for frozen size-factor estimation
      --control-genes <CONTROL_GENES>
          Comma-delimited zero-based row indices used to estimate size factors
      --fit-type <FIT_TYPE>
          Dispersion trend fit type [default: parametric] [possible values: parametric, local, mean]
      --nsub <NSUB>
          Fast-VST subset size [default: 1000]
      --output <OUTPUT>
          Output TSV path
  -h, --help
          Print help
