Write DESeq2-style normalized counts

Usage: rsdeseq2 normalized-counts [OPTIONS] --counts <COUNTS> --output <OUTPUT>

Options:
      --counts <COUNTS>
          Tab-delimited count matrix with gene IDs in the first column
      --normalization-factors <NORMALIZATION_FACTORS>
          Optional gene x sample normalization-factor TSV
      --size-factors <SIZE_FACTORS>
          Optional sample-level size-factor TSV
      --method <METHOD>
          Size-factor method [default: ratio] [possible values: ratio, poscounts]
      --geometric-means <GEOMETRIC_MEANS>
          Optional gene x geometric-mean TSV used for frozen size-factor estimation
      --control-genes <CONTROL_GENES>
          Comma-delimited zero-based row indices used to estimate size factors
      --output <OUTPUT>
          Output TSV path
  -h, --help
          Print help
