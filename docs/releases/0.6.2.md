# rsdeseq2 0.6.2

This release updates the Rust crates for numerical routines, model formulas,
and shrinkage to 0.1.2. The workspace crates use MIT for their source.
Dependencies such as nalgebra and ICU4X carry their own license terms.
[Numeric](https://crates.io/crates/rcompat-numeric/0.1.2) ·
[Formula](https://crates.io/crates/rcompat-formula/0.1.2) ·
[Shrinkage](https://crates.io/crates/rcompat-shrinkage/0.1.2)

The formula engine implements the R profiles’ reduction and rounding rules in
Rust, including binary128 accumulation on Linux arm64. TSV readers now report
bad record widths and invalid UTF-8 with line numbers. The independent
Pasilla validation panel is available as a checksum-verified download.
