# rsdeseq2 0.5.0

Prepared on `dev`; no tag, GitHub release or registry publication has been made.
The Rust crate, R package, backend and vendored core all use version 0.5.0.

## Included behavior

- Shared Rust fitting, inference, normalization, transformations and supported
  normal/ashr/apeglm shrinkage. R translates requests and constructs objects.
- Native formula expressions, factor coding, polynomial groups, term ordering,
  offsets and bounded expansion. Custom formula functions are rejected.
- Restricted saved-dispersion and likelihood expressions translated without R
  execution; supported saved locfit profiles evaluated in Rust.
- Replacement-aware later queries, validated fitted state, bounded result
  batches and shared warning/optimizer-control policies.
- Coefficient-owned posterior probability summaries with shape/identity checks.
  The posterior identity field is private; construct objects through fitting APIs.
- Configurable posterior grid budgets, shared cancellation and safe R interruption/
  reuse. CLI diagnostics borrow retained Cook's matrices.
- Tooling grouped by purpose, current documentation, operational R locks under
  `config/r-reference/`, and OS metadata excluded from Rust/R packages.

The [supported contract](../native-supported-contract.md) and
[compatibility limits](../compatibility.md) define the implemented API.
This is not complete DESeq2/Bioconductor compatibility.

## Validation and distribution

All nine executed [CI jobs](../testing-parity.md#ci-status) passed at `62825c0`:
Rust/Python, both R lanes, five platforms and full GTEx. The pinned R lane also
passed independent fresh references, interruption/reuse and Linux sanitizers.
Original-reference bounds and exact standalone/wrapped checks remain separate.
R package checks retain the known Rust compiled-symbol warning.

[Precision, speed and memory](../reports/gtex-native-wald-benchmark.md) preserve the
measured executable/environment identities; the version bump does not relabel
saved timings as new 0.5.0 measurements. The [release procedure](../release.md)
binds checked packages and target archives to committed source before publication.
