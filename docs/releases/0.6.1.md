# rsdeseq2 0.6.1

This patch release uses version 0.1.1 of the Rust crates for numerical
primitives, R-style formula design matrices, and empirical Bayes shrinkage.
Each dependency has a new README with a runnable Rust example.
[Numeric](https://crates.io/crates/rcompat-numeric/0.1.1) ·
[Formula](https://crates.io/crates/rcompat-formula/0.1.1) ·
[Shrinkage](https://crates.io/crates/rcompat-shrinkage/0.1.1)

The release workflow tests the packaged `rsdeseq2` archive with its locked
crates.io dependencies. The R source archive bundles the same versions for
offline installation. [Validation guide](../testing-parity.md#ci-status)

See the [changelog](../../CHANGELOG.md#061) and the
[0.6.0 release notes](0.6.0.md) for the API and numerical changes in the 0.6 series.
