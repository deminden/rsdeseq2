# rsdeseq2 0.6.0

## Rust API

- Use `DeseqBuilder::run(&Analysis)` for Wald and LRT analyses, fixed
  dispersions, Cook's replacement and early stops. The previous builder
  workflows are deprecated and carry migration instructions in their API
  documentation. They are scheduled for removal in 0.7.0.
- Use `Offsets` and the canonical stage inputs for normalization factors,
  dispersion search, GLM fitting and transformations.
- Select `NumericProfile` at runtime. Standalone callers default to
  `portable`. The R package selects the host R profile by default, including
  `r-binary64` on Linux arm64 and Windows.
- The shared formula, numerical and shrinkage implementations live in the
  independently versioned `rcompat-*` crates. The R source package carries
  its own offline Cargo dependencies.
- `DeseqError` is non-exhaustive. Match specific errors or use `kind()` for a
  coarse classification. The unused execution modes and unimplemented
  `FitType::GlmGamPoi` were removed.

## Numerical behavior

R-compatible rank screening, rank-deficient GLM initialization, the
parametric-to-local dispersion fallback and dataset-level `poscounts` now
follow the corresponding DESeq2 paths. `Analysis::beta_prior(true)` supports
the expanded normal-prior Wald fit for eligible formula designs.

The [changelog](../../CHANGELOG.md) describes the changed behavior and
deprecations. The [supported contract](../native-supported-contract.md)
records the supported workflows and their limits.
