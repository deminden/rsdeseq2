# rsdeseq2 0.7.0

This release makes the code match its MIT licence. Every file is now either
written independently for this project or uses published coefficients or
public-domain tables, and the [provenance ledger](../provenance/ledger.md)
records how each part was written. The Rust crates for numerical routines,
model formulas and shrinkage move to 0.2.0, and a new crate compares strings
in R's collation order.
[Collation](https://crates.io/crates/rcompat-collate/0.1.0) ·
[Numeric](https://crates.io/crates/rcompat-numeric/0.2.0) ·
[Formula](https://crates.io/crates/rcompat-formula/0.2.0) ·
[Shrinkage](https://crates.io/crates/rcompat-shrinkage/0.2.0)

Versions 0.6.2 and 0.1.2 declared MIT while still containing reduction
schedules taken from OpenBLAS (BSD), a rank rule following R's GPL Fortran,
a branch citing R's GPL `qf.c`, and MIT-licensed ports whose notices are
now gone with the code. In 0.7.0:

- The Linux x86_64 and Linux arm64 R profiles are removed. Linux uses
  `r-binary64`, which agrees with R at the reference tolerances but no
  longer reproduces Linux R's last bits.
- The QR rank rule, the polynomial QR and its reductions, the F-quantile
  limits, the special functions, the apeglm-style L-BFGS and the
  ashr-compatible SQP policy were rewritten from written specifications,
  published papers and black-box runs of R, without the earlier code.
- `nalgebra` is replaced by dense kernels in `rcompat-numeric`, and the
  ICU4X collation crates (Unicode-3.0) by `rcompat-collate`, whose weights
  were derived from black-box runs of R. Every build, the R package
  included, depends only on MIT, Unlicense or Zlib crates. The `formula`
  feature is gone: locale collation is always available. The root collation
  follows R for every code point, 29 tailorings (Swedish, Danish, Polish,
  Russian, Turkish, Greek, Canadian French, German phonebook and others)
  follow R's order for those locales, and other tailored locales are
  rejected.

Results change in the last digits. Against 0.6.2, DESeq2 fits and results
move by at most 3e-7 relative and no adjusted p-value crosses 0.05 or 0.1,
on the golden panel and on the eleven GTEx contrasts against DESeq2.
apeglm-style modes on a few GTEx genes move by up to 0.02 (under 0.1
posterior standard deviation).

The 43 low-level functions deprecated in 0.6.0 and the `math::qr` alias are
removed; their `Offsets`, `GlmInput` and `DispersionFitInput` replacements
give the same output. The changelog lists each one.
